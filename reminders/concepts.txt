# Linear Regression example =>
+ Using a model to make predictions:
	[ y = mx + b ]
- y	-> output (exmpl: prediction for wether tomorow)
- x	-> input (exmpl: actual wether today)
- m, b	-> model params
* Explanation: [y] is our prediction, [x] is the input, the accuracy of [y] is determened by those [m] & [b] parameters.
the quality of our predictions are going to be determened by how well those parameters aligned with reality.

----- How do we pic those two parameters soo they fit to reality? ----------
+ Training phase:
- in training we wanna minimize the defirence between our models prediction and real world data. we do this by calculating the loss and minimise it.

                         ‖ ⌈y1⌉   ⎛   ⌈x1⌉     ⌈1⌉ ⎞ ‖²
                         ‖ │y2│   ⎜   │x2│     │1│ ⎟ ‖
             L(m, b) =   ‖ │. │ - ⎜ m │. │ + b │.│ ⎟ ‖
                         ‖ │. │   ⎜   │. │     │.│ ⎟ ‖
                         ‖ ⌊yn⌋   ⎝   ⌊xn⌋     ⌊1⌋ ⎠ ‖

L(m,b)             -> loss function (this is what quantify our loses)
yn                 -> Actual values.
xn                 -> inputs like the previous example.
⎛   ⌈x1⌉     ⌈1⌉ ⎞
⎜   │x2│     │1│ ⎟
⎜ m │. │ + b │.│ ⎟  -> predicted values.
⎜   │. │     │.│ ⎟
⎝   ⌊xn⌋     ⌊1⌋ ⎠
GOAL: finding parameter values of [m] & [b] that give the smallest loss L(m,b)

------------ we can solve this problem in a closed form using math -------------

                 ⌈x1  1⌉                 ⌈y1⌉
                 │.   .│       ⌈m⌉       │. │
     Let,   X =  │.   .│ , θ = ⌊b⌋ , y = │. │
                 ⌊xn  1⌋                 ⌊yn⌋
- X -> set of input data that we colect.
- y -> set of target data that we collect.
+ we can combine them to find out optimal parameters.
    - Loss Function now is : L(θ) = ‖y - Xθ‖² = (y - Xθ)ᵀ(y - Xθ)
                                              = yᵀy - 2θᵀXᵀy + θᵀXᵀXθ
- Compute gradient (works like derivative) of L(θ) : L'(θ) = -2Xᵀy + 2XᵀXθ
* Explanation: We can find the values of [θ] that minimize the loss function by computing
 its gradiant [L'(θ)] seting it to zero (L'(θ) = 0) and then solving for our parameter values [θ]:
   L'(θ) = 0  ->  -2Xᵀy + 2XᵀXθ = 0  ->  XᵀXθ = Xᵀy
- When the dataset is large, we prefer gradient descent instead of the matrix inverse, because it scales better
                                ┌─────────────────┐
We can easely solve for [θ] now │ θ = (XᵀX)⁻¹Xᵀy  │ We found our optimal parametters (for training data)
                                └─────────────────┘

+ Deep Learning -> a type of machine learning which evolve training [Neural Networks] which can learn optimal features for a specific task on there own.
+ Neural Networks (NN) -> are a series of operations that can approcximate (practically) any function the fundemental building bloks of a Neural Networks are called Nuerons.
+ Neuron -> the neuron does the following steps:
                - takes a set of inputs x1 x2 x3 .... xn
                - miltiplying the inpots to some coresponding weights.
                - sums them together.
                - apply a bias term. basically adding a value to the sumation.
                - pass the whole thing to a non leanier function called activation function.
                - spit out the neuron's output Ζ

                                    ┌──────────────────┐
- single Neuron output calculation  │ Z = g(Σwᵢxᵢ + b) │ :
                                    └──────────────────┘
Z -> neuron's output.
g() -> non leanier activation function (sigmoid, ReLu).
xᵢ -> inputs.
wᵢ, b -> Paramaters (as m & b earlier).

+ we combine layers of neurons which are stacked into networks
+ as we look at this it looks a loot more like the linear model we saw before,
 but we have this g() activation function as its the cretical aspect of a neural network 
 to be able to approximate practically any function.

- example of neurons:
+---------+----------------------------------------------------------------------------------------+
| Name    | Description                                                                            |

- example of activation algorithms:
+---------+---------------------------------------------------------------------------------------+
| Name    | Description                                                                           |
+---------+---------------------------------------------------------------------------------------+
| ReLU    | max(0, x); fast, widely used in deep networks                                         |

- example of layers types:
+-----------------+-------------------------------------------------------------------------------+
| Name            | Description                                                                   |
+-----------------+--------------------------------------------------------------------------------+
| Fully Connected | Standard layer where each neuron connects to all inputs                       |
| Recurrent       | Maintains memory across timesteps; used in RNNs, LSTMs                        |

| Attention       | Computes weighted importance of different inputs; key in Transformers         |
